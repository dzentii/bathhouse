# Banya Web

Проект веб-приложения «Сандуновские бани» для выбора посещения и онлайн-бронирования мест на сеансы или сауны целиком.

Реализован backend MVP: каталог бань и отделений, расписания, тарифы, доступность, удержание ресурсов, тестовая оплата и PDF-билеты. Административный API позволяет управлять банями, продажами, заказами и сотрудниками.

**Стек:** Go, PostgreSQL, Redis, Apache Kafka, Docker Compose. Backend состоит из четырёх микросервисов: каталога, бронирования, тестовых платежей и авторизации.
