# Banya Web

Веб-сайт банного комплекса. Проект находится на начальном этапе: создана базовая структура, реализация приложения ещё не начата.

## Планируемые направления

- `frontend` — клиентская часть веб-приложения.
- `backend` — серверная часть на Go.
- DevOps — подготовка локального и будущего серверного окружения после согласования требований.

Архитектура, стек фронтенда, база данных и инфраструктурные решения будут определены после получения подробного технического задания.
