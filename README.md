# Сандуновские бани

Веб-приложение для бронирования посещений «Сандуновских бань». Посетитель может
выбрать баню и отделение, посмотреть расписание и свободные места, забронировать
места на сеанс или арендовать сауну целиком на выбранное время.

При оформлении указываются состав гостей и контакты покупателя. Система
рассчитывает стоимость по тарифам отделения и удерживает выбранные места
на 10 минут. После успешной тестовой оплаты посетитель получает электронный
билет, который можно скачать в PDF.

Для сотрудников предусмотрен административный интерфейс работы с заказами,
расписаниями, тарифами и блокировками мест. Backend также предоставляет API
для управления банями, отделениями, ресурсами, сотрудниками и паузами продаж.

Frontend написан на Angular, backend состоит из четырёх микросервисов на Go:
каталог, бронирование, платежи и авторизация. Данные хранятся в PostgreSQL,
Redis используется для кэша и ограничения запросов, Kafka — для обмена событиями
между сервисами. Локальное окружение запускается через Docker Compose.

Сейчас проект работает в режиме MVP: оплата тестовая, без списания денег.
Эквайринг, фискализация и интеграция с 1С пока не подключены.

## Запуск

Понадобятся Docker с Compose 2.24.4+, Python 3 и Node.js 24.13.1 с npm.

Из корня проекта запустите backend:

```bash
cd backend
python3 scripts/init-env.py
docker compose build catalog booking payment identity
docker compose up -d --no-build --wait
```

Если `backend/.env` уже существует, пропустите `init-env.py`.
Миграции и начальные данные применяются автоматически.

В другом терминале, также из корня проекта, запустите frontend:

```bash
cd frontend
npm ci
npm run start
```

- Приложение: http://localhost:4200
- Swagger: http://localhost:8080/swagger/

Логин и пароль администратора находятся в `backend/.env` —
`ADMIN_USERNAME` и `ADMIN_PASSWORD`.

Для остановки backend выполните `docker compose stop` из `backend/`.
Для повторного запуска — `docker compose up -d --no-build --wait`.
Frontend останавливается сочетанием `Ctrl+C`.
